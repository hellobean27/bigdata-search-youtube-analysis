# Results

이 폴더는 Spark/Hive 분석 결과 CSV를 저장한다.

## 포함 파일

- `spark_keyword_summary.csv`: 키워드별 YouTube 성과 요약
- `spark_category_summary.csv`: 분야별 YouTube 성과 요약
- `spark_correlation.csv`: Google/Naver 검색 관심도와 YouTube 성과 지표 간 상관관계
- `spark_comment_keyword_summary.csv`: YouTube 댓글 raw 데이터를 Spark로 집계한 키워드/분야별 댓글 반응 요약
