# Data

보고서에서 사용한 집계 입력값입니다.

- `origin_totals.csv`: 양평군 12개 읍·면 → 하남시 전체 이동량
- `key_od.csv`: 확인된 핵심 출발지-도착지 이동량
- `purpose_totals.csv`: 전체 이동목적별 이동량
- `policy_inputs.csv`: 차량 이용 및 정책 시나리오 계산 입력값

## 원자료

원자료는 수도권 생활이동 데이터/API 응답 및 2026-08-24~2026-08-30 이동수단 자료를 기반으로 분석했습니다.

주의: 본 폴더 값은 보고서 재현을 위한 집계값이며 원본 API/ZIP 파일 자체는 포함하지 않습니다.
